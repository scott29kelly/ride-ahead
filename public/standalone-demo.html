    How this works

    Each route is sampled into 24 evenly spaced points. Places worth seeing are found in a corridor along the route line — not a bounding box, which on any bendy route returns piles of scenery you'd never ride past — then scored on category, how far off the line they sit, and whether a photo exists, and spread out so the highlights aren't all in the first kilometre.

    In the full app, imagery is chosen by which way the camera faces: a photo taken 40 m away pointing down the road you're riding is a better preview than one at your exact position pointing at a hedge.

    Running it for real

    The full version routes anywhere, using OpenRouteService for cycling profiles and elevation, OpenStreetMap for places, and Mapillary or Street View for photography. npm install && npm run dev — it starts in this demo mode with no API keys at all.
